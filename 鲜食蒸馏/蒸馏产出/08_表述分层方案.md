# 表述分层方案

> 你选的方向：商品标签用合规措辞，功效内容移到科普/私域载体
> 目标：**保住风格 A 的全部质感，只换功效动词**

---

## 一、三层载体的划分

分层的关键不在于「话说得含蓄一点」，而在于**话说在哪里**。同一句话印在包装上和发在科普长文里，性质完全不同。

| | L1 商品标签 | L2 详情页 / 随餐卡 | L3 科普内容 / 私域 |
|---|---|---|---|
| 载体 | 包装贴纸、餐盒标签 | 商品详情页、随餐说明卡 | 公众号长文、小红书科普、社群、一对一沟通 |
| 与交易的距离 | **直接绑定商品** | 直接绑定商品 | 独立内容，不出现购买按钮 |
| 能讲什么 | 原料、规格、喂养信息、风味与质地 | 配伍逻辑、食材角色、营养成分 | 中医理论、节气养生、《黄帝内经》 |
| 功效动词 | **不用** | 只用支持类动词 | 可讲传统功用，但需框定为文化背景 |
| 风格 A 修辞 | 标题保留 | **全部保留** | 全部保留 |

**最重要的一条界限**：L3 的内容**不能直接挂在商品页上**，也不能在其中出现「本品」「购买」「下单」这类指向具体商品的表述。一旦绑定，它就从科普变成了商品宣称，分层就失效了。

正确做法是：科普文讲「长夏为什么要健脾祛湿」，讲透中医理论；商品页讲「这道菜用了茯苓、山药、薏苡仁，质地绵润」。读者自己会把两者连起来，但你没有做出宣称。

## 二、L1 商品标签：写什么

建议做成固定模板，每张标签都带这几项：

```
【品名】{菜名}
【适用】犬（成犬 / 全阶段）
【配料】{按含量递减排列的原料表}
【净含量】{}g
【建议喂食量】{按体重的分档表，或引用配比计算器结果}
【储存】-18℃冷冻保存，解冻后 24 小时内食用完毕
【保质期】{}
【过敏原提示】本品含 {麸质 / 豆类 / 乳制品 / 甲壳类}
【换食提示】首次食用请与原有饮食按 1:3 起逐步替换，7–10 天过渡完成
【重要声明】本品为鲜食佐餐，不能替代兽医诊疗、处方粮或药物。
　　　　　　　犬只如有疾病史或正在服药，请咨询兽医后食用。
```

**标题可以保留风格 A 的命名法**——「甘夏火鸡耘虾片」这类是商品名，不是功效宣称。但 `·` 之后的功能定位需要斟酌：

| 原标题后缀 | 判断 | 建议 |
|---|---|---|
| 清暑生津 | 药用宣称 | 改「夏日轻食」或直接省略 |
| 长夏脾胃运化 | 药用宣称 | 改「长夏时令」 |
| 呼吸系统润养 | 药用宣称 | 改「清润时令」 |
| 倒春寒支气管缓释 | 药用 + 疾病 | 改「早春时令」 |
| 肠道菌群环境驱动 | 偏营养学，尚可 | 可保留或改「膳食纤维配方」 |
| 春醒肝脾 ALT 调衡 | 药用 + 指标 | 标签上改「低脂配方」，ALT 相关内容移至 L3 |
| 高阶神经 6.0 | 含义模糊，反而安全 | 可保留 |

「适宜/不适宜」两栏我建议**保留**，但转成中性的适用性描述：不写「适宜胆汁淤积犬」，写「本配方为低脂结构，脂肪含量 X%」，让家长和兽医自己判断。这样既保住了信息价值，又不构成疾病宣称。

## 三、功效动词转换表

这是核心工具。左边一律不用，右边随便用。

### 必须删除，无替代

| 表述 | 说明 |
|---|---|
| 抗癌、防癌、抗肿瘤 | 最高风险，任何载体都不能用，包括小红书 |
| 治疗、治愈、根治 | 药品用语 |
| 预防 ×× 病 | 疾病预防宣称 |
| 止咳、平喘、止泻、镇静、抗惊厥 | 药效动词 |
| 抑制 ×× 通路 / 抑制 NF-κB | 药理机制宣称 |
| 消炎、抗炎、抗菌 | 药效动词 |
| 降血糖、降血压、降血脂、降胆固醇 | 药效动词 |
| 排毒、解毒 | 药用概念 |
| 提高免疫力、增强免疫力 | 官方解读里点名的典型违规表述 |

### 可以换个说法

| 原表述 | 替代表述 |
|---|---|
| 清热解毒 | 适合暑热时节 / 清爽调和 |
| 健脾渗湿、健脾祛湿 | 帮助维持消化舒适度 / 温和易化的膳食结构 |
| 润肺化痰 | 为呼吸道黏膜提供润泽的营养基础 |
| 疏肝利胆 | 低脂结构 减轻脂质消化负担 |
| 补气血 | 提供血红素铁与 B 族维生素 |
| 利尿、通淋 | 高含水结构 帮助维持日常饮水量 |
| 明目、护眼 | 提供叶黄素与玉米黄质等视觉相关营养素 |
| 美毛、护毛 | 为被毛角质形成提供营养支持 |
| 去泪痕 | 支持眼周日常清洁状态 |
| 抗氧化 | 提供天然抗氧化营养成分 |
| 促进消化 | 帮助维持消化节律 |
| 调理肠胃 | 温和的肠道营养支持 |
| 安神助眠 | 为神经系统提供营养基础 |
| 保肝护肝 | 低负担蛋白结构 |
| 缓解关节疼痛 | 提供胶原蛋白与关节相关营养素 |

### 一直很安全，可放心用

你现有文案里这批表述本来就写得对，继续用：

> 有助于维持 · 可参与 · 具有一定支持作用 · 为…提供营养支持 · 为…提供基础
> 承担…的角色 · 帮助构建…结构 · 使…更加平稳 · 让…更易被利用
> 提供…的营养来源 · 在…方面提供支持

## 四、风格 A 的四种修辞，一个都不用丢

这是分层方案最要紧的一点：**需要改的只是功效动词，不是文风**。

| 修辞手法 | 是否受影响 | 说明 |
|---|---|---|
| 否定式定义（不在于 X 而在于 Y） | 不受影响 | 「其意义不在于补 而在于托住体力」完全合规 |
| 配伍角色语（承担…的角色） | 不受影响 | 「它在整道菜中承担的是液相润化的角色」是描述而非宣称 |
| 对偶四字（润而不寒） | 基本不受影响 | 描述食材性质与口感，不是疗效 |
| 引号锁概念（"津液底盘"） | 不受影响 | 自造概念，反而比直白功效词安全 |
| 节气引言 | L2 需淡化，L3 可full | 讲天地时令没问题，讲「此时该治什么」有问题 |
| 古今语汇并置 | 保留 | 这是你的护城河，一定要留 |

## 五、实例：47 号完整改写示范

拿问题最多的那道做例子。

### 原文（部分）

> 春水梨露豚园卷肉龙·倒春寒支气管缓释
>
> 川贝母 清化痰热 缓咳止喘 为此道菜的 肺系主调 清润化痰之法
> 尤其适合换季期间 川贝的加入 使整道菜升级为支气管缓释型调养 让气道舒展
>
> 荆芥穗 宣肺散郁 疏风而不烈 倒春寒的本质是"风邪反复"荆芥穗性轻扬
> 走表而不燥 能帮助犬只在冷热交替中缓解鼻塞 喷嚏 轻度咽痒等反应

### L1 商品标签

```
【品名】春水梨露豚园卷肉龙
【配料】豚园猪瘦肉、高山水梨蒸露、百合、薄荷、有机白萝卜、
　　　　晒干雪梨丁、有机花下藕、有机金瓜
【净含量】___g
【建议喂食量】见随餐卡
【储存】-18℃冷冻，解冻后 24 小时内食用
【过敏原提示】本品含猪肉
【重要声明】本品为鲜食佐餐，不能替代兽医诊疗、处方粮或药物。
```

原料表里川贝母换成百合、荆芥穗换成薄荷，来自选材池的替代方案。

### L2 详情页 / 随餐卡

> 春水梨露豚园卷肉龙
>
> 晚春未尽 夏意已探 昼暖夜凉 风邪反复 便是所谓"倒春寒"
> 这一餐为春夏交界期而作 取春末之润 润而不寒 化燥而不腻
>
> 新鲜无激无抗豚园猪 取其精修瘦肉部分 蛋白结构稳定
> 是换季期最适合做"底盘"的肉源之一 它的意义不在于补
> 而在于托住体力与免疫消耗 稳定的氨基酸供给能支撑修复
>
> 高山水梨蒸露 清润不寒 水梨蒸露不是果汁 也不是甜饮
> 而是取其"润性"与"清气" 蒸露方式使梨的清润更温和 减少生冷刺激
> 它在整道菜中承担的是"液相润化"的角色
> 为口咽与呼吸道黏膜提供润泽的营养基础
>
> 百合 质地温润 富含黏液质与多糖 是这道菜的润养主调
> 在春夏交界的干燥时节 为整体餐食增添一份柔和的润度
>
> 薄荷 气息轻扬 天然挥发油带来清新的风味层次
> 也让整道餐食在冷热交替的季节里 显得更加轻快不滞

**注意看**：否定式定义、引号锁概念、对偶四字、配伍角色语，四种修辞一个没少。空格断句、无标点的风格完全保留。删掉的只是「清化痰热 缓咳止喘」「缓解鼻塞 喷嚏」这些疗效动词，换成了营养支持向的表述。

节气引言保留了，因为「昼暖夜凉 风邪反复」是在描述天气，不是在描述疾病。

### L3 科普内容（公众号 / 小红书）

这一层可以放开写：

> 《倒春寒时，狗狗为什么容易咳嗽？聊聊春末的肺脾同调》
>
> 可以完整讲：中医的风邪理论、肺主皮毛、脾为生痰之源、
> 换季期犬只呼吸道敏感的生理机制、川贝母在传统食养中的地位、
> 哪些体质的狗需要注意……
>
> 文末：本文为传统食养文化科普，不构成诊疗建议。
> 犬只出现持续咳嗽、呼吸急促等症状，请及时就医。

**但这篇文章里不出现任何商品名、不放购买链接、不写「我们家的××餐」。** 它是独立内容。

## 六、执行建议

1. **L1 模板先固定下来**，这是每张标签都要用的，做一次就一劳永逸。
2. **L2 是主战场**，你现有的 36 篇文案基本都属于这一层，按转换表逐篇过一遍即可，工作量不大——因为要改的只是每篇里三五个动词。
3. **L3 是新增内容**，可以慢慢做。它其实是你最好的引流资产：真正讲透理论的科普内容，比种草笔记更能建立专业信任，而且完全没有宣称风险。
4. 我写自动生成 skill 时，会把转换表编码成硬规则，并按 L1/L2/L3 三档分别出稿。

## 七、最后提醒一句

分层解决的是**宣称风险**，解决不了**安全风险**。

即便走定制鲜食路径、即便文案措辞完全合规，`05_文案专业审查.md` 里那七个安全问题依然成立——川贝母的生物碱毒性、丹参的抗凝作用、白桦茸的草酸盐、菊苣促胆囊排空对梗阻犬的危险，这些跟你怎么写文案毫无关系。

**换句话说：措辞可以分层，配方不能。**

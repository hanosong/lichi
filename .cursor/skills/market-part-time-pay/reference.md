# 计算参考

## 核心定义

```text
hᵢ = 第 i 天约定计薪工时
T  = 约定总计薪工时 = Σhᵢ
B  = 整场全勤底薪总额
Hₒ = 加班时薪
O  = 方案测算采用的预计加班工时；未明确时为0
A  = 预计加班工资 = Hₒ × O

F  = 整场不可退摊位费总额
D  = 本场承担的摊位装置费用
X  = 本场往返快递或运输费用
K  = 固定出摊成本 = F + D + X

c  = 商品成本率，默认50%
M  = 商品毛利率 = 1 − c
a  = 主办方营业额抽成比例
g  = 营业额贡献率 = M − a = 1 − c − a

eᵢ = 第 i 天预计营业额
E  = 预计总营业额 = Σeᵢ
R₀ = 保本营业额及销售提成起提线
d  = 固定成本负担率
q  = 自动连续提成率
```

整场全勤底薪覆盖全部约定兼职时间。“最低工资”不作为经营公式术语，统一称为“整场全勤底薪”或“全勤基础工资”，且不声称该金额符合当地劳动法规。

加班只指约定兼职时间之外、经双方确认的额外工作。加班工资独立计算，不参与提成：

```text
预计加班工资 A = 预计加班工时 O × 加班时薪 Hₒ
实际加班工资 = 实际加班工时 × Hₒ
```

方案设计时未明确预计加班安排的，按 `O=0、A=0` 测算。

## 固定出摊成本

```text
K = F + D + X
```

- 摊位费只计不可退金额，可退押金不计入。
- 摊位装置可重复使用时，只计用户明确由本场承担的金额；未明确分摊方式时先询问。
- 物流费用只计本场往返快递、货运或运输，不与顾客订单配送费重复。
- 商品采购成本不是固定出摊成本，按实际营业额乘商品成本率计算。
- 主办方营业额抽成不是固定成本，按实际营业额计算。

## 营业额贡献率

每增加1元营业额，在支付商品成本和主办方抽成后可用于覆盖固定成本、人工和经营结余的金额为：

```text
g = 1 − c − a
```

必须满足：

```text
g > 0
```

若 `g≤0`，每增加1元营业额都无法形成正向贡献，停止生成正式方案。

主办方若使用保底抽成、阶梯抽成或其他非统一口径，不能使用单一 `a`，必须按实际费用函数逐段计算。

## 真实保本营业额

全勤且按预计加班安排执行时，在尚未发放销售提成前：

```text
R₀ = (K + B + A) ÷ g
```

在 `R=R₀` 时：

```text
营业额贡献 = R₀ × g = K + B + A
经营结余 = 0
```

因此 `R₀` 同时作为销售提成起提线。只有营业额超过 `R₀` 的部分才计算提成。

这是真实盈亏保本线，不再使用“市集费用占商品毛利上限”或原成本安全线公式。

## 自动连续提成率

默认最高提成率：

```text
qₘₐₓ = 5%
```

固定成本负担率：

```text
d = K ÷ (E × g)
```

计算时将 `d` 限制在 `0～1`：

```text
d' = min(1, max(0, d))
```

自动提成率：

```text
q = qₘₐₓ × (1 − d')
```

该公式保证：

- `0% ≤ q ≤ 5%`；
- 固定出摊成本越高，`q` 越低；
- 预计营业额或营业额贡献率越高，固定成本负担越轻，`q` 越接近5%；
- 当固定出摊成本已经用完预计营业额的全部贡献时，`q=0`。

还必须校验：

```text
q < g
```

若 `q≥g`，停止生成方案并调整商品成本率、抽成或最高提成率，不能让每增加1元营业额后的经营结余下降。

提成率内部至少保留四位小数。对外可显示两位百分比，但工资计算必须使用同一结算精度，不能因展示取整形成另一套结果。

## 工资和经营结余函数

对任意实际营业额 `R`：

```text
若 R ≤ R₀：
    销售提成 Q(R) = 0
    不含加班费的工资 P(R) = B

若 R > R₀：
    销售提成 Q(R) = (R − R₀) × q
    不含加班费的工资 P(R) = B + Q(R)
```

最终应付工资：

```text
最终应付工资
= 应付底薪
+ 销售提成
+ 实际加班工时 × Hₒ
```

在全勤且实际加班与预计一致时，经营结余为：

```text
若 R ≤ R₀：
    N(R) = R × g − K − B − A

若 R > R₀：
    N(R) = R × g − K − B − A − (R − R₀) × q
         = (g − q) × (R − R₀)
```

因为 `q<g`，超过保本线后每增加1元营业额，员工工资增加 `q` 元，经营结余增加 `g−q` 元。

达到预计总营业额 `E` 后继续使用相同提成率，不设置工资封顶。

## 冲突处理

### 预计营业额不高于保本线

```text
E ≤ R₀
```

这表示按预计营业额无法收回固定出摊成本、全勤底薪和预计加班工资，在预计目标内也不会产生销售提成。

停止生成正式方案，列出：

```text
预计经营缺口 = K + B + A − E × g
至少需要增加的营业额 = R₀ − E
```

让用户选择调整预计营业额、底薪、固定出摊成本、商品成本率、主办方抽成或预计加班安排。

### 固定成本负担达到100%

```text
d ≥ 1
```

此时自动提成率为0。说明预计营业额贡献连固定出摊成本都无法完全覆盖，必然也无法覆盖底薪；通常会同时触发 `E≤R₀`。

### 实际加班与预计不同

方案发布前使用预计加班工资计算并固定提成起点。实际加班增加时：

- 实际加班工资必须另行支付；
- 重新计算店主实际盈亏和实际保本线；
- 不得在结算时向上调整已经约定的提成起点，以此减少兼职已经产生的提成。

## 每日进度

### 保本进度

优先按每日预计营业额权重分配：

```text
第 i 天保本进度 = R₀ × eᵢ ÷ E
```

若每日预计营业额相同，则平均分配。若某天明确不承担销售目标，则该天保本进度为0，其余日期按预计营业额比例分配。

### 标准目标

第 i 天标准目标直接使用输入的 `eᵢ`。

### 冲刺目标

用户未提供时默认：

```text
第 i 天冲刺目标 = eᵢ × 110%
```

进度数字可按10元、50元或100元等现场沟通粒度取整，但不得改变提成公式。

## 计算场景

店主版至少测算：

1. 低于保本线；
2. 刚好达到保本线；
3. 保本线与预计目标之间；
4. 刚好达到预计目标；
5. 超过预计目标10%左右；
6. 一个便于沟通的更高营业额。

每个场景计算：

```text
商品成本 = R × c
商品毛利 = R × M
主办方抽成 = R × a
销售提成 = max(0, R − R₀) × q
最终应付工资
经营结余 = R − 商品成本 − 主办方抽成 − K − 最终应付工资
排班综合时薪 = (应付底薪 + 销售提成) ÷ 实际约定计薪工时
是否保本
```

兼职 PDF 展示保本起提线、提成率、工资示例、加班规则、工作内容和行为红线，不显示商品成本率、固定出摊成本、主办方抽成、固定成本负担率或经营结余。

## 未全勤

默认底薪折合时薪：

```text
基础折合时薪 = B ÷ T
```

未全勤底薪：

```text
应付底薪 = 基础折合时薪 × 实际约定计薪工时
```

已经产生的销售提成正常结算，不得把全部提成作为迟到、早退或请假的统一处罚。约定排班之外经确认的实际加班工资仍按 `实际加班工时 × Hₒ` 另行计算。

迟到、早退只按上面的计薪工时折算底薪，不另加固定罚款。

## 已确认的行为红线

每一场店主版和兼职版都写入下列规则。除这些规则外，不得自行增加扣款项目或扣款金额。

```text
1. 未经允许打折：少收金额从应付工资扣除。
   未经允许赠送：按该产品当时标价从应付工资扣除。
2. 迟到、早退：该时段不计薪，底薪按折合时薪 × 实际计薪工时。
   销售提成仍结算，不另加固定罚款。
3. 现场活动券和现场赠送：必须先与店主确认。
   未经确认赠出的，按当时标价从应付工资扣除。
4. 不认可本品牌手作则不要接。接下后不得诋毁品牌。
   不良影响保留追责，不从工资中另扣固定金额。
5. 预报有雨必须盖雨布；店主要求搬仓必须配合。
   因此造成的货物损失按售价从应付工资扣除，差额另追。
```

这些扣款是结算规则，可以写进兼职版。兼职版仍不得出现商品成本、固定出摊成本、主办方抽成或经营结余。

## 数值精度

- 内部计算至少保留四位小数。
- 店主版金额保留两位小数，百分比保留两位小数。
- 对兼职展示时可简化到角或元，但必须声明最终结算规则。
- MD 与 PDF 必须使用同一组底层计算结果。
- 不允许因展示取整导致保本线、提成率或工资发生实质变化。

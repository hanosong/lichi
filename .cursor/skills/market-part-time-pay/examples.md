# 示例

示例用于校验计算思路，不得把金额、城市或档位直接套到新活动。行为红线、工作内容和招募自我介绍见 SKILL.md，每一场都要写入，不要从这些计算示例里省略。

## 示例一：固定成本自动降低提成率

### 输入

```text
市集名称：七日宠物零食市集
兼职日期：10月1日—7日
每日约定兼职时间：13:00—22:00
加班时薪：17元
整场全勤底薪总额：1071元
预计每日营业额：1000元
摊位费总额：1000元
摊位装置费用总额：400元
出摊物流费用总额：200元
主办方营业额抽成比例：0
```

默认商品成本率50%，无预计加班。

### 计算

```text
约定总工时 T = 9 × 7 = 63小时
预计总营业额 E = 1000 × 7 = 7000元
固定出摊成本 K = 1000 + 400 + 200 = 1600元
营业额贡献率 g = 1 − 50% − 0% = 50%
预计加班工资 A = 0元

保本营业额 R₀
= (1600 + 1071 + 0) ÷ 50%
= 5342元

固定成本负担率 d
= 1600 ÷ (7000 × 50%)
= 45.7143%

自动提成率 q
= 5% × (1 − 45.7143%)
= 2.7143%
```

### 推荐规则

```text
总营业额不超过5342元：
    销售提成 = 0

总营业额超过5342元：
    销售提成 = (营业额 − 5342元) × 2.7143%

最终应付工资
= 1071元底薪 + 销售提成 + 实际加班工资
```

### 场景

```text
5000元营业额：
    提成0元
    工资1071元
    经营结余 = 5000×50% − 1600 − 1071 = -171元

5342元营业额：
    提成0元
    工资1071元
    经营结余0元

6000元营业额：
    提成约17.86元
    工资约1088.86元
    经营结余约311.14元

7000元营业额：
    提成约45.00元
    工资约1116.00元
    经营结余约784.00元

7700元营业额：
    提成约64.00元
    工资约1135.00元
    经营结余约1115.00元
```

达到预计营业额后继续按2.7143%计算，不封顶。固定成本没有直接出现在兼职版 PDF 中。

## 示例二：有主办方抽成

### 输入

```text
市集名称：四日宠物零食市集
兼职日期：9月24日—27日
每日约定兼职时间：11:00—21:00
加班时薪：25元
整场全勤底薪总额：600元
预计每日营业额：3000元
摊位费总额：300元
摊位装置费用总额：200元
出摊物流费用总额：100元
主办方营业额抽成比例：2%
```

默认商品成本率50%，无预计加班。

### 计算

```text
约定总工时 T = 40小时
预计总营业额 E = 12000元
固定出摊成本 K = 300 + 200 + 100 = 600元
营业额贡献率 g = 1 − 50% − 2% = 48%

保本营业额 R₀
= (600 + 600) ÷ 48%
= 2500元

固定成本负担率 d
= 600 ÷ (12000 × 48%)
= 10.4167%

自动提成率 q
= 5% × (1 − 10.4167%)
= 4.4792%
```

推荐规则：

```text
总营业额不超过2500元：无销售提成
总营业额超过2500元：
    销售提成 = (营业额 − 2500元) × 4.4792%
```

达到12000元时：

```text
销售提成约425.52元
不含加班费的工资约1025.52元
经营结余
= 12000×48% − 600 − 600 − 425.52
= 4134.48元
```

## 冲突示例：预计营业额低于保本线

```text
固定出摊成本 K：1600元
整场全勤底薪 B：1071元
预计加班工资 A：0元
商品成本率：50%
主办方抽成比例：0
预计总营业额 E：4000元
```

计算：

```text
营业额贡献率 g = 50%
保本营业额 R₀ = (1600 + 1071) ÷ 50% = 5342元
预计经营缺口 = 1600 + 1071 − 4000×50% = 671元
至少需要增加的营业额 = 5342 − 4000 = 1342元
```

因为 `E<R₀`，停止生成正式方案。提示用户调整预计营业额、底薪、固定出摊成本或商品成本率，不能生成看似有提成但预计无法保本的方案。

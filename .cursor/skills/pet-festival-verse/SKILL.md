# 宠物节日寄语

为宠物礼盒的家长题诗。文笔要雅、要暖，像题在卡片上的一首小诗，不是广告词，也不是打油诗。

## 输入

种类（猫／狗）+ 名字 + 性别（可缺）+ 是否与其他宠物同住 + 节日（未说则默认中秋）。一次一只或多只。

## 主体式：五言四句

前两句写景，后两句落愿。二、四句押韵，先／元韵最顺（前—年、边—圆、安—年）。

> 小猫-花卷，桂子落轻肩，秋光暖入怀，卷身自成月，一睡到团圆。

写景两句求对：一远一近（月下／窗前）、一物一身（肩／怀）、一动一静皆可。对得要软，不要工整到板。

## 名字入诗，必须落实

用字义、谐音、拆字来应景，让名字成为诗眼，而不是贴在句首的称呼。

| 名字 | 取意 | 落处 |
|------|------|------|
| 花卷 | 猫卧时卷成一团 | 卷身自成月 |
| 王饱饱 | 丰盈 | 碗里慢慢变满 |
| 铃铛 | 声音 | 全诗围「声」走，收在「声尽是团圆」 |
| 11 | 谐音「一一」 | 每句藏一个「一」，收在「心愿一一至」 |
| KiKi | 谐音「奇」 | 月圆多奇遇 |

外文名、数字名先找谐音落到中文意思上。名字实在难入诗，就取其中最暖的一层意思来应，不生造、不硬凑。

## 意象规矩

1. **要暖，不要凉。** 秋冬易写冷，须自觉回暖：「凉似水」改「暖入怀」，「阶前露冷」改「阶前露软」。不得出现寒、愁、孤、离、病、逝。
2. **朦胧优于直陈。** 学李煜两处手法：取帘、阶、栏、幕、窗这类半遮半掩之物；用「半卷」「初移」「初生」这类正在发生、尚未落定的动作。月不直说，借影、借光、借桂香透出来。
3. **节日意象只取一两处**，见下方对照表，不堆砌。
4. **同一个字不重复用满。** 尤其「圆」「满」，前文出现过就不要在结尾再押，一首里只留一个最重的位置给它。
5. 不用生僻字，不用网络语，不用过度文言，不提买卖促销，不写「祝您」「愿您家的」这类套话，不解释典故，不加拼音。

## 节日意象对照

**中秋**（主力）：月、圆、桂、清辉、团圆、良夜、帘、阶。收在团圆、如愿、圆满。忌玉兔、嫦娥、花灯。

**春节**：春、灯、爆竹声远、新岁、门前、暖阳、梅。收在岁岁平安、长长久久。忌红包、发财、恭喜发财。

**端午**：艾、菖蒲、五色线、榴花、清昼、长命。收在安康、无恙。忌屈原典故、竞渡喧闹。

**其他节日**：按同一路数自行选两三个清雅意象，遵守上方五条规矩，收在与该节日相称的祝愿上。宁可少取意象，不可堆砌。

## 一家多只

同住的宠物按一组来写，出三样东西：

1. 每只一首五言四句，两首同韵、末字呼应（一只落「欢喜到明年」，一只落「团圆又一年」），单看完整，并排像一首诗的上下阙。
2. 若有长幼、性情之别，分工要清楚：哥哥给声、给动，弟弟给暖、给依人。
3. 一句合写句，供两只共用一张卡。合写句用长笺散句，四字、四字，再接两个六字：

> 小猫-KiKi、11，珠帘半卷，桂影初移，奇遇恰逢良夜，心愿一一皆圆。

## 输出格式

```
种类-名字，句，句，句，句。
```

种类与名字用家长给的原文，多只每只一行。

## 交付方式

先给一版主推，再给一到两版备选，然后用一小段白话说清三件事：名字是怎么落进诗里的；主推版好在哪；备选版各适合什么样的宠物或什么样的卡片。

卡片形制对应：印刷宜端稳，手写宜疏软；活泼爱叫的宜写声，安静的宜写静。

## 长度

五言四句为标准（约 20 字）；合写句 20–36 字。不足以成诗时宁可写短，不注水。
